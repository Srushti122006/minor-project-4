# BingePlay Streaming Analytics Using SQL

## About the Project
This project focuses on analyzing data from a fictional OTT streaming platform called BingePlay using SQL. The aim is to understand subscription revenue, user activity, content ratings, viewing patterns and customer retention.

## Objectives
- Analyze active subscriptions and monthly revenue.
- Study monthly user signups and device usage.
- Compare content ratings and performance.
- Identify binge-watching and comeback patterns.
- Analyze subscription upgrades and user engagement.
- Identify users showing potential churn signals.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- `users`
- `subscriptions`
- `shows`
- `watch_sessions`
- `ratings`

## Concepts Covered
- SELECT, WHERE and GROUP BY
- Aggregate functions
- Joins and subqueries
- Common Table Expressions (CTEs)
- Window functions
- Date calculations and conditional aggregation

## How to Run
1. Import the supplied database setup script into MySQL.
2. Select the `bingeplay` database.
3. Open `bingeplay_analysis.sql`.
4. Execute each query and review the output.
